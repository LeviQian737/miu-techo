# Miu 手帳：功能列表与初版 UI 方案

整体意象：一本日本**方眼手帐**。固定任务是一卷卷**纸胶带**，突发任务是一张张**便利贴**，完成就盖一枚**猫爪印章**，番茄钟用「正」字计数，Miu 住在页面右侧的**丸窓**（圆形窗）里，窗框本身就是番茄钟的进度环。

可点击原型：`design/prototype.html`

---

## 一、功能列表

### P0：这次原型已经能点的

| # | 功能 | 交互方式（无需文字说明） |
|---|---|---|
| 1 | **固定任务胶带架** | 左上一排胶带卷，**胶带长度 = 时长**。拖到时间轴上就撕下一段（原卷保留，可反复用） |
| 2 | **突发任务便利贴堆** | 左下一叠便利贴。点空白便利贴直接写，回车生成。拖进时间轴就是「移动」，便利贴从堆里消失 |
| 3 | **区块自由移动** | 时间轴 ↔ 便利贴堆 ↔ 胶带架三处都能互相拖：便利贴拖到胶带架 = 变成固定任务；时间轴上的块拖回便利贴堆 = 先不排了 |
| 4 | **时间轴** | 方眼纸上的竖向一天（08–23 点）。拖块排序、拖底边改时长、拖到垃圾桶删除（拖拽时才出现） |
| 5 | **弹性排程（解决连锁延误）** | 见第二节 |
| 6 | **番茄钟** | 选中某块点 ▶，或直接点丸窓下的 ▶。25 分专注 / 5 分休息，■ 随时结束。正在做 A 时对 B 点 ▶：A 在此刻被「撕开」，做完的部分留在原处，剩下的部分自动排到 B 后面 |
| 7 | **自动记录** | 每段专注自动画进时间轴最右侧的「实绩」细栏（铅笔斜线），并在任务块上加一笔「正」字 |
| 8 | **盖章完成** | 选中块点印章图标，盖上猫爪章，后续任务自动前移 |
| 9 | **像素 Miu** | 像素画风，按照片画的细长身材（大眼睛黄绿色、高耳朵、灰色虎斑、额头 M 纹、白下巴白喉咙、浅灰爪、深色尾尖），独立预览页 `design/miu-pixel.html`。空闲：眨眼、偶尔甩尾巴、隔一会儿打大哈欠，90 秒没人理就打盹 / 专注：绑头巾，两只爪子轮流敲键盘 / 休息：先打哈欠再侧身伸长躺在坐垫上打呼 / 盖章：蹦一下冒爱心 / 计划出问题：担心冒汗。**按住来回摸**：闭眼呼噜、尾巴快摆、冒像素爱心；**点一下**：蹦一下；眼睛会跟着鼠标转 |
| 10 | **风格切换按钮** | 右上角色卡按钮，目前只有「方眼手帐」一套，另外两格占位 |

### P1：确认方向后再做

- 跨天：溢出托盘里的任务一键进入明天，明天的固定胶带自动铺好
- 「重新起笔」：点「现在」红线上的猫爪，以此刻为起点重新分配缓冲垫
- 一周回顾：计划 vs 实绩对比，看哪类任务总是超时（自动建议它的默认时长）
- 番茄钟时长可调，结束时轻提示音 + 系统通知
- 本地持久化（目前刷新即重置）
- 更多画风（例如「和纸夜色」深色主题、「昭和喫茶」复古主题）

### P2：以后

- 多设备同步、日历导入（只读，导入成钉住块）
- Miu 的更多小动作：长时间没操作会睡着、连续完成 4 个番茄会叼来小鱼干

## 二、怎么解决「一个任务出问题，后面全部连带出问题」

普通日程是一串硬时间：前面晚 20 分钟，后面每一格都错了。原型里用了四个机制，让延误**被吸收、被拦住、被看见、被处理**：

1. **流动块 vs 钉住块（拦住）**
   默认任务都是「流动」的：只记顺序和时长，不记死时间，前面延误就整体顺延。
   开会、吃饭这类必须准点的点图钉 📌 钉住。流动块会**绕开**钉住块，延误传到钉子这里就停了，不会把会议推走。如果延误真的撞上钉子，钉住块会变红、Miu 会担心，提示你要处理。

2. **缓冲垫（吸收）**
   时间轴里放着几块「坐垫」（上面睡着一只小猫）。前面超时会**先压扁坐垫**，坐垫被吃完才往后推。提前完成，坐垫会变厚，相当于赚到了休息。
   坐垫可以从胶带架上拖新的出来，也可以删掉。

3. **超时可视化（看见）**
   正在做的任务一旦超过计划时长，超出部分会显示成红色斜线并持续变长，你能直接看到「延误正在发生」，而不是等到下一个任务才发现。

4. **溢出托盘 + 一键压缩（处理）**
   顺延到 23 点之后放不下的任务，自动掉进底部「🌙 托盘」，不再假装今天能做完。托盘旁有一个压缩按钮：把之后还没开始的任务按「最小版本」缩短（默认缩到一半，例如健身 45→25 分钟），直到放得下。实在放不下的就留在托盘，拖回便利贴堆或明天。

> 原型里可以用顶部的「原型控制」时间滑块快进：把时间拖到 10:10，看「深度工作」超时 → 坐垫被压扁 → 后面顺延 → 在「例会」钉子前停住。

## 三、视觉方案

| 项 | 选择 |
|---|---|
| 纸面 | 冷调方眼纸 `#F7F8F5`，格线 `#DDE6E9` |
| 墨色 | 墨 `#2B2B33`，淡墨 `#6B6E78` |
| 胶带色 | 抹茶 `#B5D3A7`、空色 `#B3C8E6`、山吹 `#F5D27A`、樱 `#F4BCC8`、藤 `#CDBFE3` |
| 便利贴 | `#FFF0A6` |
| 朱（只用于印章、「现在」红线、正字、超时） | `#E0533F` |
| Miu | 灰 `#8D9197`，深灰斑纹 `#5F6369`，白胸口白爪，粉耳朵 |
| 字体 | 霞鹜文楷（中文手写感，与日文 Klee One 同源）；番茄钟数字用 Zen Maru Gothic 圆体 |

无文字说明的设计手段：
- **形状即类别**：胶带 = 固定，便利贴 = 突发，坐垫 = 缓冲，图钉 = 准点
- **尺寸即时长**：胶带越长时间越长，块越高时间越长
- **拖拽中才出现的落点**：插入线带时间、垃圾桶、各区域虚线框
- **Miu 即状态提示**：它的姿势就是番茄钟状态，它的表情就是今天计划的健康度

## 四、需要你确认的问题

1. **平台**：原型按「网页 / PWA」做，电脑三栏，手机单栏可用。你主要在手机还是电脑上用？如果要做 iOS 原生 App，下一步技术选型会不同。
2. **一天的范围**：现在是 08:00–23:00，要改吗？
3. **缓冲垫**：手动放（现在的做法），还是自动每 2 小时插一块？
4. **番茄钟**：25/5 固定，还是需要长休息（每 4 个番茄休息 15 分钟）？
